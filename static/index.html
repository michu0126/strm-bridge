播放路径

媒体库读取 .strm → 访问 STRM Bridge → CD2 获取当前网盘链接 → HTTP 302 跳转到网盘。

部分媒体服务器会自行代理远程视频。客户端是否完全绕过 NAS，还取决于媒体服务器的直放策略、客户端解码能力和网盘对 IP / User-Agent 的限制。
